# Guidelines

- use `pnpm` not `npm`; alias pn=pnpm.
- always use the apex skill for token management.
- high quality output is expected. use modern standards.
- development or temp docs/files are to placed in folder `docs` while test data, random data etc like .logs are in folder `logs` - none are committed to repo.
- after each task perform a quick light diff check on the new changes and provide a sample git commit message that can be used.
- always run `pn tsc` and `pn lint:fix` after tasks.
